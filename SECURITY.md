# Seguridad y datos

Reporta fallas de forma privada al propietario del repositorio. No abras Issues con secretos, cuentas, IP públicas, UID, grabaciones o datos personales.

Nunca subas archivos `.env`, bases SQLite, certificados privados, respaldos, video, hojas de personas o configuraciones reales de cámaras. Usa únicamente los marcadores y datos ficticios incluidos.

Si un secreto llega a Git, revócalo en el proveedor, genera uno nuevo y revisa los registros. Borrar el archivo en un commit posterior no elimina el secreto del historial.
